## Estrutura do Campo `videos` Adicionado

Cada vídeo foi adicionado como um array `videos` no subtópico correspondente, com a seguinte estrutura:

```json
"videos": [{
  "id": "VIDEO_ID",
  "titulo": "Título do vídeo",
  "canal": "Nome do canal",
  "urlOriginal": "https://www.youtube.com/watch?v=VIDEO_ID",
  "embedUrl": "https://www.youtube-nocookie.com/embed/VIDEO_ID",
  "descricao": "Resumo completo do conteúdo essencial (alternativa textual obrigatória — Seção 12.2 do Escrita.md)",
  "dataValidacao": "2026-10-24"
}]
```

## Requisitos Técnicos Atendidos

### Iframe (conforme Seção 12.2)
- Domínio: `youtube-nocookie.com` (preferencial para privacidade)
- Atributos recomendados:
  - `allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture"`
  - `referrerpolicy="strict-origin-when-cross-origin"`

### Alternativa Textual Obrigatória
- **Regra (Seção 12.2):** "Vídeos são complementares: não substituem a apostila; alternativa textual completa mantida no site."
- Cada vídeo possui campo `descricao` com resumo didático completo do conteúdo, servindo como alternativa textual para:
  - Usuários com deficiência auditiva/visual
  - Ambientes onde YouTube é bloqueado
  - Casos de remoção futura do vídeo
  - Estudo offline (modo `file://`)
